# base_deb_c_builder

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/base_deb_c_builder)

This image is based on [base_deb_builder image](/base_deb_builder) and comes with Debian packaging utilities (c flavour).


Packages installed:
- cmake (3.28.3-1build7)
- bison (2:3.8.2+dfsg-1build2)
- flex (2.6.4-8.2build1)
- gcc (4:13.2.0-7ubuntu1)

Additional features:
- Configures DEBEMAIL and DEBFULLNAME environment variables
