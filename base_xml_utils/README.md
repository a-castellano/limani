# base_xml_utils

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/base_xml_utils)

This image is based on [base image](/base) and it comes with XML utils installed.


Packages installed:
- libxml2-utils (2.9.14+dfsg-1.3ubuntu3.7)
- xmlstarlet (1.6.1-4)

Additional features:
- Used for XML schema validation.
