# base_deb_perl_builder

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/base_deb_perl_builder)

This image is based on [base_deb_builder image](/base_deb_builder) and comes with Debian packaging utilities (perl flavour).


Packages installed:
- libmodule-build-tiny-perl (0.052-1)
- libmodule-install-perl (1.21-2)
- libmodule-build-perl (0.423400-3)
- dh-make-perl (0.130)
- libgit-wrapper-perl (0.048-2)
- libcatalyst-modules-perl (49)

Additional features:
- Configures DEBEMAIL and DEBFULLNAME environment variables
