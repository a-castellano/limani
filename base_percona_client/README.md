# base_percona_client

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/base_percona_client)

This image is based on [base image](/base) and comes with percona-server-client installed.


Packages installed:
- daedalus-project-mysql-utils (0.4-7)
- percona-server-client (8.4.7-7-1.noble)

Additional features:
- **daedalus-project-mysql-utils** allows you to change mysql root password
