# base_git

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/base_git)

This image is based on [base image](/base) and comes with git installed.


Packages installed:
- git (1:2.53.0-1ubuntu1)
- ca-certificates (20260601~26.04.1)
- openssl (3.5.5-1ubuntu3.3)

Additional features:
- ca-certificates is required for secure connections.
