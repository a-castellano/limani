# base

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://hub.docker.com/r/daedalusproject/base)

This image is based on Ubuntu focal image and uses Daedalus Project and Windmaker repos.

```
deb http://repo-focal.windmaker.net/ focal main
deb http://packages.windmaker.net/ any main
deb [arch=amd64] http://packages.windmaker.net/ focal main
deb [arch=amd64] http://repo.daedalus-project.io/ focal main
```
